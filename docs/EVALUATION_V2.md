# Bound multi-seed evaluation

These native Rust examples consume an existing compiler-acceptance experiment. They do not generate Rust code, authenticate an upstream project, or promote a model. Test predictions are already observed; exploratory reports do not create a fresh holdout.

Every command begins with six positional arguments: `PREDICTIONS.csv SHA256 CORPUS.crust SHA256 GROUPS.tsv SHA256`. Digests must come from a separately reviewed inventory. Group files have exactly `project<TAB>group<TAB>split` as header, one line per corpus project, exact split agreement, and no group crossing splits. Domain names supplied as groups remain domains, not independent upstream projects.

`cargo run --release -p cogno-model --example v2_evidence_audit -- ...` validates every prediction against the hash-pinned corpus. One arm, 1–64 seeds, every admitted source exactly once per seed, binary probabilities, consistent labels/argmax, and bounded LF text are required. The only argmax tolerance is 1e-7 around a rounded f32 tie. Reports include input SHA bindings. Rows repeated across seeds are never counted as independent source samples.

`v2_group_metrics` reports accuracy, clipped NLL, and Brier score for every supplied group and split. Equal-group and source-weighted summaries are separate estimands; a large group does not dominate the equal-group result. Each source has equal weight within its group, averaged across all admitted seeds. Unique source and seed counts are printed separately. Group membership is a clustering assumption, not evidence of independence.

`v2_cluster_comparison ... OTHER_PREDICTIONS SHA SPLIT BOOTSTRAP_SEED` requires identical source/group bindings and seed sets. It computes paired B-minus-A accuracy and NLL deltas, averages sources and fixed seeds within each group, then resamples whole groups 2,000 times with deterministic unbiased index selection. The point estimate weights groups equally. Its percentile limits assume independent groups; two synthetic domains provide extremely weak uncertainty evidence and do not establish significance. This deliberately does not resample repeated seed rows as if independent. NLL improvement has a negative sign; accuracy improvement has a positive sign. Fewer than two groups is refused.

`v2_temperature_fit` selects one shared temperature over all validation sources and all seeds by mean clipped NLL, from the fixed ordered grid `1, .25, .5, .75, 1.5, 2, 3, 4, 8`. Exact ties follow that order. Test/train labels cannot enter fitting. It reports raw and calibrated NLL/Brier separately for every split, including negative results. This is exploratory postprocessing of stored rounded probabilities; it does not alter checkpoints or prove calibration on unseen data. Probabilities are clamped to `[1e-7, 1-1e-7]` before logit conversion.

`v2_selective_fit ... MAX_VALIDATION_EMPIRICAL_ERROR` selects the greatest observed validation coverage meeting the requested empirical error limit over the fixed confidence grid `.5, .55, .6, .65, .7, .75, .8, .85, .9, .95, .99`. Ties favor the lower threshold. It pools all validation seeds, then applies that one threshold to validation/test group reports without refitting. If no nonempty candidate qualifies, the policy abstains on everything and prints error `NA`, never a fictitious zero-error score. This fitted empirical constraint is not a confidence bound or guarantee on test/future errors. Accepted unique sources mean acceptance in at least one seed, while coverage uses source-seed observations.
