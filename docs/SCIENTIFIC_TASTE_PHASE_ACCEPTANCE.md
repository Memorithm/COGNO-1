# Autonomous Scientific Taste Acceptance Criteria

A change in this phase is acceptable only when all of the following remain true:

- model-origin observations cannot directly produce promotion validations;
- hard runtime constraints remain outside taste influence;
- promotion requires at least two non-model confirmations and the configured deterministic confidence threshold;
- contradictory evidence blocks activation;
- benchmark metrics are deterministic and integer-only;
- longitudinal history is bounded and monotonic per preference;
- generation persistence remains atomic and hash-linked;
- corrupted or forked artifacts fail closed;
- a live verified profile is not silently replaced by the autonomous evaluator.
