# Autonomous Scientific Taste Security Boundary

Autonomous scientific-taste evaluation is advisory and evidence-producing. It does not grant tool, filesystem, network, policy, kernel, or model authority.

SciAgent model output is quarantined. Runtime observations are observation-only. Promotion validation may originate only from deterministic SciRust evaluation or explicit user action. Verified profile installation remains sealed and is performed only through the existing transactional generation and restart-time verification path.
