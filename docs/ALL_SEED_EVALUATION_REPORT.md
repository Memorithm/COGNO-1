# All-seed frozen binary evaluation

`cargo run --release -p cogno-model --example bpe_multiseed_report -- SEEDS_TSV SEEDS_SHA CORPUS CORPUS_SHA test`

The independently digest-checked manifest contains 2–64 rows (no header), each `seed<TAB>checkpoint_path<TAB>checkpoint_sha256`, bounded to 64 KiB. Paths are absolute or relative to the manifest. Seeds are canonical decimal u64, unique, sorted for output and verified against each checkpoint's encoder seed. Duplicate checkpoint digests are refused. Freeze and commit the complete planned seed manifest before evaluating; the tool cannot detect upstream omissions. Every model must share configuration and tokenizer except encoder seed. Training schedules are not encoded in inference checkpoints: users must ensure they are from one frozen training protocol.

Each checkpoint and admitted full-partition CRUST001 corpus is digest checked. Every selected record must infer successfully, otherwise the entire report aborts before stdout; no capacity refusal or failed seed is silently excluded. Every seed gets confusion counts (TN, FP, FN, TP), precision/recall/F1 for each class, accuracy and macro F1. The prediction is pass only if p_compile > .5. Both ground-truth classes are required; precision is explicitly 0 when a class is never predicted. F1 is `2TP/(2TP+FP+FN)` with zero denominator convention 0. Macro F1 averages the two class F1 scores.

The summary gives unweighted mean and population variance (`sum((x-mean)^2)/number_of_seeds`) of accuracy and macro F1 across **all** manifest seeds. This variance is descriptive, not a confidence interval or sample-variance estimate. There is no winner selection, training, model promotion, corpus compilation or execution. Results on a tiny already-observed diagnostic do not establish expert Rust ability or generalization. Tests cover confusion calculations, absent predicted class, invalid inputs, known population variance, sorted/duplicate/canonical seed manifests and input bounds.
